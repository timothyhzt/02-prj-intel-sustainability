# Project 2: Intel Sustainability Journey

This project presents Intel's sustainability goals in an interactive timeline.
It uses Bootstrap 5 for the responsive layout:

- The main content uses three responsive columns for the project overview, timeline, and localization controls.
- The `LTR` and `RTL` buttons change the page's text direction for localization testing.
- The localization column is ready for a Bootstrap contact form in a future step.

The page uses the Bootstrap CDN, so an internet connection is needed to load Bootstrap's styles and JavaScript.
